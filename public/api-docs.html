UYSA ERP v5.0 API

Yemek Sektoru ERP Sistemi — RESTful API Dokumantasyonu

JWT + API Key Auth PHP 8.2+ MySQL 8.0 Provider-Agnostic AI
Base URL: https://your-domain.com/uysa_api.php?action={action}
Auth: Header Authorization: Bearer {JWT} veya X-UYSA-Token: {API_TOKEN}
Content-Type: application/json (POST istekleri icin)

Finans & Muhasebe (fin.*)

▶
GETfin.accounts
Hesap planini listeler (ana hesaplar + alt hesaplar).
POSTfin.accountSave
Yeni hesap olusturur veya gunceller.
ParamTipAciklama
codestringHesap kodu (orn: 100, 100.01)
namestringHesap adi
typestringasset / liability / equity / revenue / expense
parent_idint|nullUst hesap ID
GETfin.journalList
Yevmiye kayitlarini listeler.
POSTfin.journalSave
Cift tarafli yevmiye kaydi olusturur. Borc = Alacak zorunlu.
ParamTipAciklama
datedateKayit tarihi (YYYY-MM-DD)
descriptionstringAciklama
linesarray[{account_id, debit, credit}] — toplam borc = alacak
Ornek Istek
{
  "date": "2026-03-26",
  "description": "Hammadde alimi",
  "lines": [
    {"account_id": 5, "debit": 1500.00, "credit": 0},
    {"account_id": 2, "debit": 0, "credit": 1500.00}
  ]
}
POSTfin.journalPost
Yevmiye kaydini onaylar (draft → posted).
POSTfin.journalVoid
Yevmiye kaydini iptal eder (void).
GETfin.invoiceList
Fatura listesi (satis + alis). Filtre: type, status.
POSTfin.invoiceSave
Fatura olusturur. Satirlar ile birlikte kaydeder.
GETfin.paymentList
Odeme kayitlarini listeler.
POSTfin.paymentSave
Odeme kaydeder. Fatura bagliysa otomatik durum gunceller.
GETfin.bankAccounts / fin.bankTransactions
Banka hesaplari ve hareketleri.
GETfin.trialBalance / fin.balanceSheet / fin.incomeStatement
Mali raporlar: Mizan, Bilanco, Gelir Tablosu.
GETfin.dashboard
Finans ozet paneli: toplam gelir, gider, alacak, borc.

AI Asistan

▶
Provider-Agnostic: Anthropic (Claude), OpenAI (GPT) veya OpenClaw destekler.
AI_PROVIDER env ile secim yapilir. Varsayilan: anthropic.
POSTaction=ai.chat
ERP icin AI asistan. ERP verileri otomatik baglam olarak eklenir.
ParamTipAciklama
messagestringKullanici sorusu (maks 2000 karakter)
Istek
POST /uysa_api.php?action=ai.chat
{"message": "Bu ayin toplam geliri ne kadar?"}
Yanit
{"ok":true,"response":"Bu ayin toplam geliri **45,230 TL**...","provider":"anthropic"}
GETaction=ai.history
AI sohbet gecmisi. Params: ?source=erp&limit=50

Telegram Bot

▶
POSTaction=telegram.webhookPublic
Telegram webhook endpoint'i. Bot mesajlarini isler.
POSTaction=telegram.setup
Telegram webhook'unu kurar (setWebhook API).
Bot Komutlari:
/start — Baslat | /baglanti — ERP hesabi bagla | /stok — Stok ozeti | /fatura — Son faturalar | /personel — Personel listesi | /ozet — Genel ozet | /dusukstok — Dusuk stok alarmlari | /siparisler — Bekleyen siparisler | /yardim — Komut listesi

Dogal dil sorgulari otomatik olarak AI asistana yonlendirilir.
