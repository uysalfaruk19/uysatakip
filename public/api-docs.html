Kimlik Doğrulama

API 3 farklı kimlik doğrulama yöntemini destekler:
1. JWT Bearer Token (önerilen): Authorization: Bearer <token>
2. API Key: X-API-Key: <key>
3. Legacy Token: X-UYSA-Token: <token>
POST ?action=login Public JWT token al
ParametreTipAçıklama
usernamestringKullanıcı adı
passwordstringŞifre

Örnek İstek

curl -X POST "https://app.up.railway.app/uysa_api.php?action=login" \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"sifre"}'

Örnek Yanıt

{"ok": true, "token": "eyJhbGciOiJIUzI1NiJ9...", "user": "admin", "role": "admin"}

AI Asistan (Provider-Agnostic)

Anthropic (Claude), OpenAI (GPT), OpenClaw destekler. ERP verileri bağlamında akıllı yanıtlar.

POST?action=ai.chatAuth
AI'ya soru sor
ParametreTipAçıklama
messagestringSoru (max 2000 karakter)

Örnek

curl -X POST "https://app.up.railway.app/uysa_api.php?action=ai.chat" \
  -H "Authorization: Bearer TOKEN" \
  -d '{"message":"Bu ayki düşük stoklu ürünler?"}'
{"ok":true,"response":"Düşük stok: Dana Kıyma 5kg (min:20kg)...","provider":"openclaw"}
GET?action=ai.historyAuth
Sohbet geçmişi (&source=erp|telegram)
Provider Ayarları (.env):
AI_PROVIDER=openclaw — anthropic | openai | openclaw
AI_API_KEY=your-key
AI_BASE_URL=https://api.openclaw.com/v1/chat/completions (opsiyonel)
AI_MODEL=model-name (opsiyonel)
